## 🌟 Overview

This repository houses the source code for the personal portfolio of **Nihar Ramoliya**, a Machine Learning & Data Science Engineer specializing in predictive modeling, exploratory data analysis (EDA), and interactive dashboard solutions.

The website is crafted with pure Vanilla web technologies (semantic HTML5, modern CSS3, and lightweight JavaScript) to ensure **instant loading**, **zero build dependencies**, and a **clean, responsive design**.

---

## ✨ Features

- 🌓 **Adaptive Dark / Light Mode**: Sleek dark slate default theme with emerald accents, coupled with a crisp light mode. Theme preferences are persisted in `localStorage`.
- 📱 **Fully Responsive Layout**: Engineered with mobile-first CSS Grid & Flexbox, delivering an optimal experience across phones, tablets, laptops, and ultra-wide screens.
- 🔍 **Interactive Project Case Study Modals**: In-depth architecture breakdowns, findings, and technical takeaways for each project accessible via animated accessible modals.
- 📋 **One-Click Email Copying**: Integrated clipboard action with visual toast notification confirmation.
- 📊 **Dynamic Impact Metrics**: Highlights 50K+ records processed, 92% model accuracy, and interactive data science achievements.
- ⚡ **Zero-Dependency Architecture**: No heavy frameworks, no bloated bundles — pure, fast, native web standards.
- 🎯 **SEO & OpenGraph Optimized**: Complete meta tags, title hierarchies, semantic landmarks, and social sharing metadata.

## 🛠️ Tech Stack

- **Markup & Structure**: Semantic HTML5 with accessibility ARIA attributes.
- **Styling & Design System**: Modern CSS3 (Custom properties / CSS variables, Glassmorphism, CSS Grid, Flexbox, Keyframe animations).
- **Typography**: [Inter](https://fonts.google.com/specimen/Inter) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) via Google Fonts.
- **Interactivity**: Vanilla JavaScript (ES6+, `IntersectionObserver`, `Clipboard API`, `localStorage`, Event delegation).
- **Icons**: Inline scalable vector graphics (SVG).

## 🚀 Quick Start

No Node.js, npm, or build tools required.

### 1. Clone the repository
```bash
git clone https://github.com/niharr05/Portfolio.git
cd Portfolio
```

### 2. Run locally

**Option A: Open directly**
Double-click `index.html` in your file manager, or open it in any browser:
```bash
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

**Option B: Local development server**
```bash
# Python 3
python3 -m http.server 8080

# Or via Node.js (npx)
npx serve .
```
Then visit `http://localhost:8080` in your browser.

## 🌐 Free 1-Minute Deployment

### Deploy to GitHub Pages
1. Go to your GitHub repository: [github.com/niharr05/Portfolio](https://github.com/niharr05/Portfolio)
2. Click **Settings** > **Pages** (left sidebar).
3. Under **Branch**, select `main` and root folder `/` (root).
4. Click **Save**. Your site will be live at:
   ```
   https://niharr05.github.io/Portfolio/
   ```

### Deploy to Vercel or Netlify
- Drag and drop this folder into [Vercel](https://vercel.com) or [Netlify](https://www.netlify.com) for instant global CDN deployment and custom domain support.
